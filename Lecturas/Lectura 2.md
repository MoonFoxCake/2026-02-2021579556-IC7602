
1. Explique la diferencia entre una WAN y una MAN.

La diferencia entre una WAN y una MAN es la distancia, mientras que una MAN esta pensada para una ciudad de aproximadamente unos 100 kilometros, una WAN ya se piensa para varios paises o continentes como por ejemplo el internet.

2. Explique las diferencias entre una red orientada a conexión y una red no orientada a conexión

Una red orientada a conexion esta hecha para que se haga un camino nuevo para cada conexion que se crea, a esto tambien es se tiene handshaking, que en palabras simples, se revisan los credenciales antes de enviar informacion.

En cambio una red no orientada a conexion es distinta, aca no existe el handshaking, y aca cada paquete tiene que tener una direccion por lo cual estos dos sistemas son muy distintos.

Para resumir, una red orientada a conexion es mas lenta, y se hace un camino para cada conexion, una red no orientada a conexion es mas rapida pero cada paquete ocupa su propia direccion


3. ¿Qué es una red punto a punto? Explique cómo implementarla de acuerdo con la lectura.

Una red punto a punto es un tipo de red el cual consiste de varias conexiones entre nodos, por lo tanto la informacion sale de su origen, y para poder llegar a su destino tiene que pasar a traves de varios nodos para llegar a su destino, por lo cual pasa por varios lados.

En cuanto a como implementarlo, puede ser por redes de intercambio de paquetes o intercambio de circuito

4. Explique los conceptos de FDM y TDM

FDM es frequency division multiplexing, este modo es que se comparte la frecuencia de un link con las conexiones que se hacen con el mismo. 
TDM es time division multiplexing, en este otro modo se separa por tiempo, entonces se dividen en tiempos, por lo cual cada tiempo se dedica a una conexion, y estos no se pueden compartir.
